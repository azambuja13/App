# Calculadora de Precificação - Versão CLOUD

Esta é a versão com backend PostgreSQL e sincronização multi-dispositivo.

## Características:
- ✅ Sincronização entre dispositivos
- ✅ Backup automático na nuvem
- ✅ Sistema de licenças
- ✅ Auto-refresh a cada 5 segundos
- ✅ Fallback offline
- ⚠️  Requer licença ativa

## Como usar:
1. Ative sua licença na primeira execução
2. Preencha os dados do evento
3. Clique em "Salvar" - dados vão para a nuvem
4. Acesse de qualquer dispositivo com a mesma licença
