📦 Importar Ingredientes Padrão para PostgreSQL

O que faz: Importa os 328 ingredientes padrão (DEFAULT_INGREDIENTS) para o banco de dados PostgreSQL.

Quando usar: Na primeira vez que você acessa o sistema, ou se os ingredientes padrão não estão aparecendo.

⚠️ Importante:
  • Se você já fez login na aplicação principal, o token será detectado automaticamente
  • Caso contrário, cole seu token de autenticação abaixo (formato: NOME-email-PRM-...)
  • Apenas ingredientes que ainda não existem no banco serão importados (evita duplicatas)
  • Este processo pode levar alguns segundos
💡 Deixe em branco para detectar automaticamente do localStorage/sessionStorage
