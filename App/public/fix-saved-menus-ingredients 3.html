🔧 Fix: Ingredientes em Cardápios Salvos

Problema: Cardápios salvos antigos não têm os ingredientes dos pratos, então a lista de compras aparece "Sem nome" com R$ 0,00.

Solução: Este script vai buscar os ingredientes de cada prato no banco de dados PostgreSQL e atualizar os cardápios salvos.

⚠️ Importante: Você precisa ter feito login na aplicação principal pelo menos uma vez.
